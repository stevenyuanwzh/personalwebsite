# Engineering Portfolio — Next.js + React + TypeScript

Built with Next.js 16.3.3, React 19.2.8 and TypeScript. Intended for deployment on Vercel.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customize

1. Replace `YOUR NAME` in `components/Nav.tsx`, `app/page.tsx`, and metadata if desired.
2. Replace `you@example.com` with your real email.
3. Replace each `ImagePlaceholder` component with `next/image` when you add your own images.
4. Add new project routes under `app/projects/<project-name>/page.tsx`.
5. Reuse `ProjectCard` on the homepage for each new project.

## Deploy on Vercel

Import the project from GitHub or run a Vercel deployment from the project folder. Vercel automatically detects Next.js.
